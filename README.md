# frogger-bevy
A remake of the original frogger game written in the bevy game engine.

This Mini-Project is honestly not meant as anything the public should ever get to see, but rather is just a little exercise for me to improve my skills in learning bevy and rust. If you want, feel free to use this code to learn from, or any other purpose you desire, but consider this code probably won't follow best practices, nor will be actively maintained.
